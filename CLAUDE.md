# Site da SIB Parauapebas

Site da **Segunda Igreja Batista em Parauapebas (SIB Parauapebas)**.

- Tipo: site estático com várias páginas, feito em HTML, CSS e JavaScript puros (sem frameworks).
- Instagram oficial: https://www.instagram.com/sibparauapebas/
- Inspiração de estrutura e estilo: o site central.online. **Nunca copiar** textos, imagens, logotipo ou marca deles. Usar só como referência de organização e visual.

## Regras do projeto

1. **Idioma:** responder sempre em português.
2. **Nomes de arquivos e pastas:** em minúsculas, sem acento e sem espaço. Use hífen para separar palavras.
   - Certo: `quem-somos.html`, `culto-domingo.jpg`
   - Errado: `Quem Somos.html`, `culto_domingo.JPG`, `programação.html`
3. **Conteúdo separado do código:** textos, anúncios, vídeos e fotos que mudam com frequência ficam na pasta `conteudo/`. Assim dá para atualizar o site sem mexer no código.
4. **Código simples e comentado:** o responsável pelo projeto é iniciante. Prefira soluções simples e explique nos comentários o que cada parte faz.
5. **Responsivo:** o site precisa funcionar bem no celular, no tablet e no computador. Comece pelo layout do celular (mobile first).
6. **Forma de trabalhar:** explique cada passo antes de executar e peça confirmação.

## Estrutura de pastas

```
site/
├── assets/
│   ├── css/      → arquivos de estilo (cores, fontes, layout)
│   ├── js/       → arquivos JavaScript (interatividade)
│   └── img/      → imagens fixas do site (logo, ícones)
├── conteudo/     → conteúdo editável: textos, anúncios, vídeos, fotos
└── CLAUDE.md     → este arquivo de regras
```
